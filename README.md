# パシュトのおならジャンプ（操作感プロトタイプ）

黒猫の魔法使いパシュトが、おなら噴射魔法で冒険する2D横スクロールアクションの試作です。
ブラウザだけで動き、PCとスマホの両方で遊べます。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーを立てて開きます。

```bash
python3 -m http.server 8000
```

その後 http://localhost:8000 を開きます。

| 操作 | パソコン | スマホ |
|---|---|---|
| 移動 | ← → / A D | 左下の ◀ ▶ |
| ジャンプ | Space / Z / ↑ | ジャンプボタン |
| おなら | X / Shift（長押しで噴射し続ける） | おならボタン |
| 調整画面 | P | 右上の「調整」 |
| やり直す | R | 右上の「やり直す」 |

- 地上でおなら：おならジャンプ（長押しでさらに上昇）
- 地上で ← → を押しながらおなら：おならダッシュ
- 空中でおなら：下に噴射して上昇（長押しで噴射し続ける）
- ゲージ不足：プスー…と鳴って一瞬だけ浮く
- 煙はしばらくその場に残り、触れた敵にダメージ
- ゲージは着地中に回復

## 調整画面

すべての数値をスライダーで変えられます。設定はブラウザに保存され、
「数値をコピー」で現在の値をJSONとして取り出せます。

## おなら音

WebAudioでその場で合成しています。8種類のプリセットに毎回ランダムな揺らぎを加え、
直前と同じ種類は選ばないようにしています。

## Spineアニメーション

`assets/spine/` の `pasyuto.json` / `pasyuto.atlas` / `pasyuto.png` を読み込んで表示します
（ランタイムは `vendor/spine-canvas.min.js`、spine-canvas 4.2）。読み込めないときは `assets/pasyuto.png` の1枚絵で表示します。

| ゲームの状態 | 再生するアニメ |
|---|---|
| 立ち止まっている | idle |
| 空中で上昇中 / 落下中 | jump_start → jump_loop / fall_start → fall_loop |
| プスー / 敵にぶつかった | pusu / hurt |
| 地上で移動中 | run（移動速度に合わせて再生速度を変える） |
| 噴射開始 | fart_start → fart_air（ループ） |
| おならダッシュ中 | fart_air |
| 2〜5秒ごと（噴射中以外） | blink（トラック1に重ねる） |

- 煙はポイントアタッチメント `butt` の位置から出ます。
- 書き出しは「乗算済みアルファ（PMA）」をオフにしてください。Canvas 2Dで描くため、オンだと縁が黒ずみます。
- blink に入っているおしりの表示切り替えキーは、読み込み時に取り除いています。
