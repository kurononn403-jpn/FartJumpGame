# パシュトのおならジャンプ（操作感プロトタイプ）

黒猫の魔法使いパシュトが、おなら噴射魔法で冒険する2D横スクロールアクションの試作です。
ブラウザだけで動き、PCとスマホの両方で遊べます。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーを立てて開きます。

```bash
python3 -m http.server 8000
```

その後 http://localhost:8000 を開きます。

| 操作 | パソコン | スマホ |
|---|---|---|
| 移動 | ← → / A D | 左下の ◀ ▶ |
| ジャンプ | Space / Z / ↑ | ジャンプボタン |
| おなら | X / Shift（長押しで噴射し続ける） | おならボタン |
| 調整画面 | P | 右上の「調整」 |
| やり直す | R | 右上の「やり直す」 |

- 地上でおなら：おならジャンプ（長押しでさらに上昇）
- 地上で ← → を押しながらおなら：おならダッシュ
- 空中でおなら：下に噴射して上昇（長押しで噴射し続ける）
- ゲージ不足：プスー…と鳴って一瞬だけ浮く
- 煙はしばらくその場に残り、触れた敵にダメージ
- ゲージは着地中に回復

## 調整画面

すべての数値をスライダーで変えられます。設定はブラウザに保存され、
「数値をコピー」で現在の値をJSONとして取り出せます。

## おなら音

WebAudioでその場で合成しています。8種類のプリセットに毎回ランダムな揺らぎを加え、
直前と同じ種類は選ばないようにしています。
